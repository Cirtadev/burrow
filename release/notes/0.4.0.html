• New VPN engine: OpenVPN 3.11.8 with Mbed TLS 3.6 LTS, which adds TLS 1.3. The previous one, OpenVPN 3.6.1 with Mbed TLS 2.7, no longer got security fixes.
  • Older configurations keep working: Burrow leaves out OpenVPN 2 settings the new engine refuses (log and status files, management, …) and turns ns-cert-type server into remote-cert-tls server.
  • No longer supported: the Blowfish (BF-CBC) and 3DES ciphers, SOCKS proxies, proxies that accept only NTLM logins, server certificates marked only with the old Netscape server type, and the fragment, verify-hash, peer-fingerprint, capath and x509-username-field settings.
